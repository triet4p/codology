## [2026-11-26] Dùng `codology` làm package Python gốc

**Decision:** Package Python gốc của framework là `codology`.
**Alternatives considered:** `oac`, tên xuất hiện trong cấu trúc package đề xuất trước đó.
**Reason:** Người dùng quyết định thống nhất namespace package với tên dự án Codology; Ontology as Code (OaC) tiếp tục là thuật ngữ khái niệm.
**Consequences:** Các package con dự kiến của Sprint 3 nằm dưới `codology`; cấu trúc chi tiết vẫn được quyết định khi thiết kế triển khai.
